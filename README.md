# Backend — Harmoniq

REST API для платформи статей: реєстрація/авторизація користувачів, робота зі статтями, категоріями та збереженими статтями.

## Стек технологій

- Node.js + Express
- База даних: MongoDB ///URL///
- Автентифікація: JWT (access + refresh токени)
- Документація API: Swagger (///URL///)

## Встановлення та запуск

```bash
git clone git@github.com:yevhenii-priadko/backend-harmoniq.git
cd backend-harmoniq
npm install
code .
```

Створити файл `.env` у корені проєкту:

```env
PORT=3000
DB_URL=(///URL///)
JWT_ACCESS_SECRET=your_access_secret
JWT_REFRESH_SECRET=your_refresh_secret
```

Запуск сервера для розробки:

```bash
npm run dev
```

## Архітектура сервера

- Підключення необхідних модулів (express, cors, dotenv, mongoose тощо)
- Налаштування CORS для дозволу взаємодії з дозволеними хостами
- Централізована обробка помилок (middleware для вилову й форматування помилок)

## База даних

- Обговорити та зафіксувати структуру БД: колекції `Users`, `Articles`, `Categories` та зв'язки між ними
- Підключення БД до проєкту через змінну середовища `DB_URL`

## Документація ендпоінтів

## Auth

| Метод | Ендпоінт | Доступ | Опис |
|---|---|---|---|
| POST | `/auth/register` | Публічний | Реєстрація користувача |
| POST | `/auth/login` | Публічний | Логін користувача, видає access/refresh токени |
| POST | `/auth/logout` | Приватний | Вихід користувача з системи |
| POST | `/auth/refresh` | Захищений (refresh token) | Оновлення сесії користувача |

**Реєстрація — валідація полів:**
- `name`: обов'язкове, 2–32 символи
- `email`: обов'язкове, до 64 символів
- `password`: обов'язкове, 8–64 символи
- `avatar`: необов'язково, файл до 1 MB

**Логін — валідація полів:**
- `email`: обов'язкове, до 64 символів
- `password`: обов'язкове, 8–64 символи

**Middleware авторизації** — перевіряє наявність токену та відповідність прав доступу для приватних/захищених маршрутів.

## User

| Метод | Ендпоінт | Доступ | Опис |
|---|---|---|---|
| PATCH/POST | `/users/avatar` | Приватний | Додавання/зміна аватару користувача |
| GET | `/users/:id` | Публічний | Інформація про користувача (автора) |
| GET | `/users/me/saved-articles` | Приватний | Список збережених статей поточного юзера |
| GET | `/users/:id/articles` | Публічний | Список статей, створених юзером |
| POST | `/users/me/saved-articles/:articleId` | Приватний | Додати статтю до збережених |
| DELETE | `/users/me/saved-articles/:articleId` | Приватний | Видалити статтю зі збережених |
| PATCH | `/users/me` | Приватний | Оновлення інформації про користувача (додатково) |

## Articles

| Метод | Ендпоінт | Доступ | Опис |
|---|---|---|---|
| GET | `/articles` | Публічний | Список статей + пагінація (+ фільтри та сортування — додатково) |
| GET | `/articles/:id` | Публічний | Отримання статті за id |
| POST | `/articles` | Приватний | Створення статті |
| PATCH | `/articles/:id` | Приватний | Редагування статті за id |
| DELETE | `/articles/:id` | Приватний | Видалення статті за id |

**Створення статті — валідація полів:**
- `title`: обов'язкове, 3–48 символів
- `description`: обов'язкове, 100–4000 символів
- `photo`: обов'язкове, до 1 MB
- `date`: обов'язкове, формат `рррр-мм-дд`
- `author`: обов'язкове, 4–50 символів

## Categories (додатково)

| Метод | Ендпоінт | Доступ | Опис |
|---|---|---|---|
| GET | `/categories` | Публічний | Список категорій статей: `popular`, `general` |
